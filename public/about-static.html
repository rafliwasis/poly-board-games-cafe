On weekdays, an All Day Pass is Rp 40.000. On weekends, you can choose a 3 Hours Pass for Rp 35.000 or an All Day Pass for Rp 50.000. Each pass applies per person — everyone at one table must choose the same pass type.

With the All Day Pass, there's no time limit — your table is yours for the whole day. With the 3 Hours Pass, you can extend your session anytime using the same pass type (though you can't upgrade to an All Day Pass).
